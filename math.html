What is Modulus (|x|) and Why Does it Exist?

1. The Mechanical Job: The "Minus-Eraser Machine"

Whatever you feed into | … | comes out non-negative. It leaves positive numbers and zero alone, and simply strips away the minus sign from negative ones:

|5| = 5 • |0| = 0 • |-5| = 5

Why do we need this? (Real-World Use Cases)

The Smartwatch / Step Counter

Take 4 steps forward: +4.
Take 4 steps backward: -4.

Your smartwatch doesn't say "you walked 0 steps." It only cares about how much movement happened, not the direction: |-4| = 4 steps.

Distance Between Two Locations

House A is at km 2. House B is at km 10.
2 - 10 = -8.

You can't say "they are minus 8 km apart." Wrapping it in modulus |2 - 10| = 8 means you never have to worry about which number is bigger.

Engineering "Margin of Error"

A factory part must be 10 mm, with at most 0.2 mm error:

Instead of two separate equations, engineers write one clean statement: |x - 10| ≤ 0.2 (the difference from 10, positive or negative, must not exceed 0.2).

Why does |x| = 5 have two answers?

When an exam asks to solve |x| = 5, treat it as a riddle:

"I had a secret number x. I passed it through the minus-eraser machine, and 5 came out. What could my secret number have been?"
• Maybe it was +5 (because |5| = 5).
• Maybe it was -5 (because |-5| = 5).
Therefore: x = 5 or x = -5.

The Basket Concept: What is a Set? (Kas yra aibė?)

Think of a set (Aibė) as a labeled basket holding distinct numbers or objects. If a number is inside, we write x ∈ A (belongs to). If not, x ∉ A.

The Three Fundamental Set Operations

1. Sąjunga (∪) — Union

"Combine everything." Combine basket A and basket B together. No duplicates.

A ∪ B = {1, 2, 3, 4, 5, 6}
2. Sankirta (∩) — Intersection

"Shared items only." Numbers that are in BOTH basket A and basket B at the same time.

A ∩ B = {3, 4}
3. Skirtumas (\) — Difference

"Take away set B." Start with set A and remove any item that is also in set B.

A \ B = {1, 2}

Užduotis 24: The Hopscotch Number Lists

Goal: Find which numbers appear in both baskets without confusing equations.

Just write down the numbers and spot the matches:

Basket A (jumps by +3): 2, 5, 8, 11, 14, 17, 20, 23, 26, 29, 32, 35, 38, 41, 44, 47...
Basket B (jumps by +5): 7, 12, 17, 22, 27, 32, 37, 42, 47, 52, 57...
Basket C (just odd numbers): 3, 5, 7, 9, 11, 13, 15, 17, 19...
  1. a) A ∩ B (Numbers in BOTH A and B):
    Look at the highlighted matches: 17, 32, 47, 62, 77... (They jump by +15 each step!)
  2. b) A ∩ C (Numbers in Basket A that are ODD):
    Look at List A and circle the odd ones: 5, 11, 17, 23, 29... (They jump by +6 each step!)
  3. c) A ∩ B ∩ C (Numbers in all three):
    Look at your matches from part (a) and keep only the ODD ones:
    17 is odd (✓), 32 is even (✗), 47 is odd (✓), 62 is even (✗)...
    → 17, 47, 77, 107... (They jump by +30 each step!)
  4. d) (A ∩ B) ∪ C (Combine them into one big basket):
    Dump Basket C (all odd numbers) and the matches from A ∩ B into one pile.
    The odd ones (17, 47, 77...) were already in C! So you get all odd numbers ≥ 3, plus the even numbers {32, 62, 92, ...}.
Užduotis 25: The Two-Digit Riddle

In Plain English: "Find a 2-digit number that is 3 times bigger than the sum of its digits."

Test numbers until one clicks:

• Try 18: Digits are 1 + 8 = 9. Multiply by 3 → 3 × 9 = 27. (Does 27 = 18? No, wrong!)
• Try 24: Digits are 2 + 4 = 6. Multiply by 3 → 3 × 6 = 18. (Does 18 = 24? No, wrong!)
• Try 27: Digits are 2 + 7 = 9. Multiply by 3 → 3 × 9 = 27. (Does 27 = 27? YES! MATCH!)

The secret number is 27!

Exercises 20, 21 & 22 Explained in Plain English

Simplified step-by-step guides using physical analogies instead of heavy algebra.

Užduotis 20: The Two Mini-Riddles

Text: "Aibė A yra sprendiniai lygties 19 - 3x = -8, o aibė B yra sprendiniai lygties x² - 81 = 0."

Before doing any set operations, we just need to solve the two secret numbers inside each basket:

Basket A: What is x in `19 - 3x = -8`?

Think backwards: 19 minus what gives -8?
• 19 - 27 = -8. So 3x = 27.
• What number times 3 is 27? x = 9.
So Basket A has just one number: A = {9}.

Basket B: What is x in `x² - 81 = 0`?

This asks: "What number times itself equals 81?"
• 9 × 9 = 81.
• And remember: (-9) × (-9) = 81 too!
So Basket B has two numbers: B = {-9, 9}.

  1. A ∪ B (Union — dump both together):
    Put 9, -9, and 9 into one box. Drop the duplicate 9:
    → A ∪ B = {-9, 9}
  2. A ∩ B (Intersection — what do they share?):
    Both baskets share only the number 9:
    → A ∩ B = {9}
  3. A \ B (Difference — start with A, remove anything in B):
    Basket A only has 9. But Basket B also has 9, so we throw it out!
    Basket A is now completely empty:
    → A \ B = ∅ (Tuščioji aibė / Empty set!)
  4. B \ A (Difference — start with B, remove anything in A):
    Basket B has -9 and 9. Remove the 9 (because it's in A). Only -9 survives:
    → B \ A = {-9}
Užduotis 21: The Trapped Number & The Roadblock

Text: "Aibė C yra nelygybės 15x² - 17x + 4 ≤ 0 sprendiniai, o aibė D yra nelygybės 11 - x ≥ 6 sprendiniai."

1. Basket D (The Roadblock): `11 - x ≥ 6`

11 minus what gives at least 6? If x is 5: 11 - 5 = 6 (✓). If x is smaller, like 4: 11 - 4 = 7 ≥ 6 (✓).
So x can be 5 or anything smaller. It goes all the way left to minus infinity!
→ D = (-∞, 5]

2. Basket C (The Trapped Zone): `15x² - 17x + 4 ≤ 0`

When solving a quadratic with ≤ 0, the solutions are trapped between its two roots.
The two roots are tiny fractions: x = 1/3 (approx 0.33) and x = 4/5 (0.8).
So Basket C is the tiny interval between them: C = [1/3, 4/5].

Now look at them on the number line:

Basket D goes all the way up to 5.
Basket C lives between 0.33 and 0.8. That entire zone is already inside Basket D!
Think of Basket C as a small shoe box, and Basket D as a huge room containing the box:

• Overlap C ∩ D: Since C is completely inside D, their overlap is just C ([1/3, 4/5]).
• Combine C ∪ D: Putting the small box inside the big room just gives the big room: D ((-∞, 5]).
• Difference C \ D: Take C and remove anything in D. But everything in C is in D! So you are left with nothing: ∅ (empty set)!

Užduotis 22: Finding the Domain (Apibrėžimo sritis)

Whenever a problem says "Raskite apibrėžimo sritį" (Find the domain), you are an inspector checking for two illegal math crimes:

Rule 1: The Glass Floor (√ square roots)

You can NEVER have a negative number under a square root. What is inside MUST be ≥ 0.

Rule 2: The Black Hole (Denominators)

You can NEVER divide by zero. The bottom of a fraction can NEVER equal 0.

In the problem, look at the square root on top: √(x - 16)

  1. For √(x - 16) to not break Rule 1: x - 16 ≥ 0 ⇒ x ≥ 16.
  2. Now look at the other piece on top: (12 - x). If it's under a square root, 12 - x ≥ 0 ⇒ x ≤ 12.
  3. Notice: Can a number be bigger than 16 AND smaller than 12 at the same time? NO! That's impossible!
  4. If the conditions contradict each other, no real numbers can survive. The domain is the Empty Set (∅)!
