What is Modulus (|x|) and Why Does it Exist?

1. The Mechanical Job: The "Minus-Eraser Machine"

Whatever you feed into | … | comes out non-negative. It leaves positive numbers and zero alone, and simply strips away the minus sign from negative ones:

|5| = 5 • |0| = 0 • |-5| = 5

Why do we need this? (Real-World Use Cases)

The Smartwatch / Step Counter

Take 4 steps forward: +4.
Take 4 steps backward: -4.

Your smartwatch doesn't say "you walked 0 steps." It only cares about how much movement happened, not the direction: |-4| = 4 steps.

Distance Between Two Locations

House A is at km 2. House B is at km 10.
2 - 10 = -8.

You can't say "they are minus 8 km apart." Wrapping it in modulus |2 - 10| = 8 means you never have to worry about which number is bigger.

Engineering "Margin of Error"

A factory part must be 10 mm, with at most 0.2 mm error:

Instead of two separate equations, engineers write one clean statement: |x - 10| ≤ 0.2 (the difference from 10, positive or negative, must not exceed 0.2).

Why does |x| = 5 have two answers?

When an exam asks to solve |x| = 5, treat it as a riddle:

"I had a secret number x. I passed it through the minus-eraser machine, and 5 came out. What could my secret number have been?"
• Maybe it was +5 (because |5| = 5).
• Maybe it was -5 (because |-5| = 5).
Therefore: x = 5 or x = -5.

The Basket Concept: What is a Set? (Kas yra aibė?)

Think of a set (Aibė) as a labeled basket holding distinct numbers or objects. If a number is inside, we write x ∈ A (belongs to). If not, x ∉ A.

The Three Fundamental Set Operations

1. Sąjunga (∪) — Union

"Combine everything." Combine basket A and basket B together. No duplicates.

A ∪ B = {1, 2, 3, 4, 5, 6}
2. Sankirta (∩) — Intersection

"Shared items only." Numbers that are in BOTH basket A and basket B at the same time.

A ∩ B = {3, 4}
3. Skirtumas (\) — Difference

"Take away set B." Start with set A and remove any item that is also in set B.

A \ B = {1, 2}

Exponents & Roots (Laipsniai ir Šaknys)

The Golden Rule of Fractional Powers: "The Root Tree"

Whenever you see a fraction in the exponent, like xm/n:

• The bottom number (n) is the ROOT (underground → √[n]).
• The top number (m) is the POWER (up in the branches).
Example: 1252/3 = (√[3]{125})² = 5² = 25!

1. The Negative Exponent Flip

A minus in the exponent just flips it downstairs into a fraction:

x-2 = 1 / x²
(1/25)-0.5 = 250.5 = √25 = 5
2. Multiplying & Dividing

Same base? Just add or subtract exponents:

ap • aq = ap + q
xp : xq = xp - q
3. Conjugates: (A - B)(A + B)

Whenever you see twin square roots with opposite signs, use difference of squares:

(√15 - √6)(√15 + √6) = 15 - 6 = 9

The 3 Secret Rules to Solve All Homework Problems:

Rule 1: The Root Tree (Fractions in Power)

• Top number = power in branches.
• Bottom number = root underground (√).
91/2 = √9 = 3 • 1251/3 = √[3]{125} = 5.

Rule 2: The Elevator (Minus in Power)

A minus in the power never makes a number negative! It just flips it downstairs into the basement:
x-1 = 1/x • (1/5)-1 = 5.

Rule 3: Power Arithmetic

• When multiplying (•) → ADD powers.
• When dividing (:) → SUBTRACT powers.
• When stacked (a²)³ → MULTIPLY powers (a6).

Cube Formulas & Simplifying Rational Fractions

The Two Cube Factoring Formulas (Kūbų formulės)

• Sum of cubes: a³ + b³ = (a + b)(a² - ab + b²)
• Difference of cubes: a³ - b³ = (a - b)(a² + ab + b²)

Example 3a: Canceling Common Factors in Fractions

Simplify: (b + 2) / (b³ + 8)

  1. Notice that 8 = 2³, so the bottom is a sum of cubes: b³ + 2³.
  2. Expand the bottom using the formula: (b + 2)(b² - 2b + 4).
  3. Now rewrite the fraction:
    (b + 2) / [(b + 2)(b² - 2b + 4)]
  4. Cancel the matching twin (b + 2) on top and bottom!
  5. Final Answer: 1 / (b² - 2b + 4).
Example 3d: The Multi-Step Fraction Workout

Simplify: [7(x - 2) / (x³ - 8) - (x + 2) / (x² + 2x + 4)] • (2x² + 4x + 8) / (x - 3)

  1. Factor x³ - 8 = (x - 2)(x² + 2x + 4).
  2. The first term cancels (x - 2): it becomes 7 / (x² + 2x + 4)!
  3. Now both terms inside the brackets share the exact same denominator!
    [7 - (x + 2)] / (x² + 2x + 4) = (5 - x) / (x² + 2x + 4).
  4. Factor a 2 out of the multiplier: 2(x² + 2x + 4) / (x - 3).
  5. Cancel the big quadratic twin (x² + 2x + 4) on top and bottom!
  6. Final Answer: 2(5 - x) / (x - 3) = (10 - 2x) / (x - 3).

1. The Cube Formulas (Greitosios Daugybos Formulės)

In this unit of the textbook, we expand beyond basic squares ((a+b)²) to cubes ((a+b)³ and a³ ± b³). Don't just memorize them — see the story behind the signs!

1. Sum of Cubes: a³ + b³

(a + b)(a² - ab + b²)

Intuition: First bracket keeps the + sign. The second bracket gets the "incomplete square" with a single minus in the middle!

2. Difference of Cubes: a³ - b³

(a - b)(a² + ab + b²)

Intuition: First bracket keeps the − sign. The second bracket is all positive!

3. Cube of a Binomial: (a ± b)³

(a+b)³ = a³ + 3a²b + 3ab² + b³
(a-b)³ = a³ - 3a²b + 3ab² - b³

Intuition: Coefficients are 1, 3, 3, 1! For minus, signs alternate: + , − , + , −.

Textbook Walkthrough: Pavyzdys 3

Problem: Simplify (x + 2)³ - (x - 3)³

    (x + 2)³ = x³ + 3(x²)(2) + 3(x)(2²) + 2³ = x³ + 6x² + 12x + 8.
  2. Expand the second cube:
    (x - 3)³ = x³ - 3(x²)(3) + 3(x)(3²) - 3³ = x³ - 9x² + 27x - 27.

2. Advanced Polynomial Factoring & Algebraic Fractions

In Lithuanian: Daugianarių skaidymas daugikliais. Factoring is simply running multiplication backward to cancel identical factors in fractions!

The 3-Step Strategy to Factor Anything:
  1. Step 1: Greatest Common Factor (GCF) out first! If every term has x or a common number like 3, pull it out before doing anything else.
  2. Step 2: Inspect the remaining shape.
    • 2 terms? Check for difference of squares (a² - b²) or cubes (a³ ± b³).
    • 3 terms? Quadratic trinomial (ax² + bx + c = a(x - x_1)(x - x_2)).
    • 4 terms? Group in pairs (ac + bc + ad + bd = c(a+b) + d(a+b) = (a+b)(c+d)).
  3. Step 3: Cancel identical brackets top and bottom! (Never cancel individual terms, only full multiplied brackets).
Textbook Walkthrough: Simplifying Algebraic Fractions

Expression: [ (m³ - 125) / (m² + 5m + 25) ] : [ (m² - 25) / (2m + 10) ]

  1. Notice cubes & squares:
    • m³ - 125 = (m - 5)(m² + 5m + 25).
    • m² - 25 = (m - 5)(m + 5).
    • 2m + 10 = 2(m + 5).
  2. Flip the division into multiplication:
    [ (m - 5)(m² + 5m + 25) / (m² + 5m + 25) ] × [ 2(m + 5) / ((m - 5)(m + 5)) ]
  3. The Great Cancellation:
    • (m² + 5m + 25) cancels completely.
    • (m - 5) cancels completely.
    • (m + 5) cancels completely.
    The only survivor is the clean number 2!
Answer: 2

3. Powers with Rational Exponents (Laipsniai su Racionaliuoju Rodikliu)

A power doesn't have to be a whole number like x³. It can be a fraction like am/n or a negative fraction like b-p/q!

The Master Bridge: Roots ↔ Fractions

For any base a > 0 and rational number m/n:

am/n = √[n]{am} = (√[n]{a})m

• Numerator (m): Normal power.
• Denominator (n): Index of the root (always goes underground in the radical notch).

The 5 Core Laws of Exponents

1. Same Base Multiplication ap • aq = ap + q

Add powers. Example: 21/3 • 22/3 = 21 = 2.

2. Same Base Division ap : aq = ap - q

Subtract powers. Example: 53/2 : 51/2 = 51 = 5.

3. Stacked Power (Tower) (ap)q = ap × q

Multiply powers. Example: (81/3)² = 2² = 4.

4. Distribute to Product (ab)p = ap • bp

Distribute the power to each factor inside.

5. Distribute to Quotient (a/b)p = ap / bp

Distribute power to top and bottom.

6. The Elevator (Negative Power) a-p = 1 / ap

Flips down to denominator. Example: 4-1/2 = 1/√4 = 1/2.

4. n-th Roots & The Domain (Apibrėžimo Sritis)

In Lithuanian: n-tojo laipsnio šaknis. A critical topic in your book is knowing when a root is legal and what numbers are allowed inside!

The Golden Odd vs. Even Rule:
Odd Roots (n = 3, 5, 7, ...)

• ALWAYS ALLOWED! Positives, zero, and negatives are all welcome.
• √[3]{-8} = -2 (because (-2)³ = -8).
• Domain: All real numbers (x ∈ ℝ).

Even Roots (n = 2, 4, 6, ...)

• STRICT GATE! Inside must be ≥ 0.
• √[4]{-16} has NO real meaning!
• Crucial identity: √[n]{an} = |a| when n is even!

Finding the Domain (Apibrėžimo Sritis): Pavyzdys 9

Question: For what x does √[4]{2x - 9} have meaning?

  1. Notice the root index is 4 (even)! Even roots forbid negative numbers.
  2. Set up the inequality: 2x - 9 ≥ 0.
  3. Add 9 to both sides: 2x ≥ 9.
  4. Divide by 2: x ≥ 4.5 (or [4.5; +∞)).
Domain: x ≥ 4.5
Odd Root Domain Comparison:

Question: For what x does √[5]{3x - 12} have meaning?
Index is 5 (odd) → An odd root can take any real number, positive or negative!
Domain: x ∈ (-∞; +∞) (visi realieji skaičiai).

The Modulus Trap: √[n]{an} for Even Roots

• √[4]{(-7)4} = |-7| = 7 (NOT -7!).
• If n is even, the answer can never be negative. Always wrap the output in absolute value |a|!

5. Moving Factors In and Out of Roots (Įkėlimas ir Iškėlimas)

In Lithuanian: Daugiklio iškėlimas prieš šaknies ženklą ir įkėlimas po šaknies ženklu. This is like packing and unpacking a suitcase!

1. Pulling Out (Iškėlimas)

Find a perfect n-th power hiding inside, take its root, and bring it outside as a single factor:
√[n]{an • b} = a • √[n]{b}

2. Pushing Inside (Įkėlimas)

To move an outside factor inside an n-th root, raise it to the n-th power:
a • √[n]{b} = √[n]{an • b}

3. Negative Sign Caution

When a < 0 and moving into an even root: LEAVE the minus sign outside! Only push the positive magnitude in:
-3√2 = -√(3² × 2) = -√18.

• √[4]{3} = √[12]{3³} = √[12]{27}.
Since 16 < 27, we immediately know √[3]{2} < √[4]{3}!

6. Rationalizing Denominators (Iracionalumo Naikinimas Vardiklyje)

In Lithuanian: Panaikinkite iracionalumą trupmenos vardiklyje. Mathematicians dislike having roots stuck in the bottom of a fraction. Here is how to banish them cleanly!

Case 1: Single Root in Denominator

Multiply top and bottom by the root needed to complete a whole power:
c / √a = (c√a) / a
c / √[3]{a} = (c√[3]{a²}) / a

Case 2: Square Root Twin (Conjugate)

If denominator has √a - √b, multiply top and bottom by its conjugate twin √a + √b!
Denominator turns into (√a)² - (√b)² = a - b!

Case 3: Cube Root Conjugate

If denominator is √[3]{a} - √[3]{b}, multiply by the incomplete square √[3]{a²} + √[3]{ab} + √[3]{b²} to trigger A³ - B³ = a - b!

Textbook Walkthrough: Pavyzdys 18 (Conjugate Multiplication)

Problem: Rationalize 4 / (√7 - √5)

  1. The denominator is (√7 - √5). Its conjugate twin is (√7 + √5).
  2. Multiply numerator and denominator:
    [ 4(√7 + √5) ] / [ (√7 - √5)(√7 + √5) ]
  3. Evaluate denominator with (A-B)(A+B) = A² - B²:
    (√7)² - (√5)² = 7 - 5 = 2.
  4. Simplify fraction:
    4(√7 + √5) / 2 = 2(√7 + √5)!
Answer: 2(√7 + √5)
Single Radical Example: 6 / √[3]{9}

Notice 9 = 3². To make a full cube 3³ = 27, we need one more 3!
Multiply top and bottom by √[3]{3}:
6√[3]{3} / √[3]{27} = 6√[3]{3} / 3 = 2√[3]{3}!
